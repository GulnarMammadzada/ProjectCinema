# 🎬 ProjectCinema  

ProjectCinema is a console-based cinema management system that allows users to manage films, actors, and reviews efficiently. The system provides an interactive menu where users can perform various operations related to films and actors.  

## 📌 Features  
- 🎞️ **Film Management**  
  - Add new films with details.  
  - Update existing film information.  
  - Delete films from the system.  
  - View detailed information about films.  
  - List all available films.  

- 🎭 **Actor Management**  
  - Add actors to specific films.  
  - Update actor details.  
  - Remove actors from films.  
  - Display all actors in the system.  

- ⭐ **Reviews & Ratings**  
  - Add user reviews for films.  
  - Calculate and display the average rating of films.  
  - Show the top-rated films based on user feedback.  

The system provides a structured and user-friendly interface for managing a collection of films and actors efficiently.
